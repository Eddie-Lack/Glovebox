# Keys

_Back to the [guide](README.md)_

The line at the bottom of the view shows the main ones.

## The mouse

| Action | What happens |
| --- | --- |
| Click | Selects |
| `Ctrl`+click | Adds to the selection, or takes away |
| `Shift`+click the ground | Drops a garib |
| Drag | Turns the camera |
| Right-click+drag | Pans |
| Scroll wheel, or middle-click+drag | Zooms |
| `Ctrl`+`Alt`+drag | Box select |
| Drag on a number field | Changes the number. `Shift` is finer, `Ctrl` is bigger |

## The keys

| Key | What it do |
| --- | --- |
| `W` | Move |
| `E` | Rotate |
| `R` | Scale |
| `F` | Focus on the selection, or on the whole level with nothing selected |
| `Home` | View all: the whole level |
| `B` | Box select |
| `A` | `+ Add` |
| `P` | Path |
| `C` | Fly |
| `T` | Test level |
| `Ctrl+A` | Select everything visible, except landscape |
| `Ctrl+D` | Duplicate |
| `Ctrl+C` | Copy the selection |
| `Ctrl+V` | Paste, also in another level |
| `Del` or `Backspace` | Delete |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` or `Ctrl+Y` | Redo |
| `Esc` | Leaves the tool you're in. With no tool on, de-selects everything |

On a Mac, `Cmd` works for `Ctrl`.

## Text size

| Key | What happens |
| --- | --- |
| `Ctrl` and `+` | Bigger text, everywhere in the window |
| `Ctrl` and `-` | Smaller text |
| `Ctrl` and `0` | Normal size again |

## While you fly

| Key | What it do |
| --- | --- |
| `W` `A` `S` `D` | Move along the view |
| `Space` | Up |
| `Shift` | Down |
| Scroll wheel | Speed |
| `C` or `Esc` | Stop flying |

## In the Path tool

| Key | What it do |
| --- | --- |
| Click the ground | Adds a point |
| `Backspace` | Takes the last point off |
| `P` or `Esc` | Leaves the tool |
